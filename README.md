# 📘 JavaScript Fundamentals

Repositório dedicado ao estudo dos fundamentos de JavaScript, com exercícios práticos focados em consolidar conceitos essenciais da linguagem.

## 🚀 Objetivo

Desenvolver domínio sobre os principais conceitos de JavaScript por meio de prática constante, incluindo:

- Manipulação de DOM
- Eventos
- Estruturas de dados
- Lógica de programação
- HTML & CSS integrados ao JS

## 📂 Estrutura do Projeto
 ```
├── DOM/ # Manipulação de elementos e árvore DOM
├── Eventos/ # Eventos (click, mouseover, double click, etc.)
├── html&css/ # Exercícios combinando HTML, CSS e JS
├── html-css/ # Variações e práticas com estilização
├── objects/ # Manipulação de objetos em JS

```

## 🧠 Conteúdos Praticados

- Variáveis (`let`, `const`)
- Tipos primitivos
- Arrays e objetos
- Funções
- Loops (`for`, `while`)
- Condicionais (`if`, `else`)
- Métodos de array (`map`, `filter`, `reduce`)
- Eventos do DOM
- Manipulação de elementos HTML

## 🛠️ Tecnologias

- JavaScript (ES6+)
- HTML5
- CSS3
